Download dscoder

One installer, and nothing else to set up. dscoder is plain Node with no packages and no database, so what you download is the whole of it.

Your computer will warn you, and here is why

dscoder is not code-signed. There is no developer certificate behind these files, so Windows and macOS both class it as software from an unidentified developer and stand in the way the first time you open it. That is a fact about how dscoder is distributed — it is not a sign that something went wrong with your download, and it will not change.

What it means in practice is one extra step on Windows, three on macOS, and they are written out in full below. It also means one thing on macOS that is easy to find out too late: an unsigned app cannot update itself, so every macOS update is a download you do by hand. On Windows, updates are automatic.

Installs for you only, into your own user folder. No administrator password is asked for.

  1. Run the installer

    Open the .exe you just downloaded. It asks where to put dscoder and makes its own Desktop and Start Menu shortcuts.

  2. Get past the SmartScreen warning

    A blue box appears saying Windows protected your PC. The button you want is not on it yet — it is hidden behind the small More info link. Click More info, and a Run anyway button appears underneath. Click that.

    This is Windows telling you it does not recognise who published the file, which is true: nobody has signed it. You will see this once, on the installer, and not again.

  3. Open dscoder

    It starts the engine, puts an icon in the notification area, and opens the window. On Windows the tray icon starts hidden under the ^ arrow — drag it onto the taskbar if you want to keep an eye on it.

    From here on, the app keeps itself up to date: it fetches new versions, checks them, and swaps them in the next time it starts — never in the middle of a run.

Apple silicon is every Mac since 2020 — the Apple menu → About This Mac says which yours is.

Updates on macOS are a manual download, every time. See step 4.

  1. Drag it to Applications

    Open the .dmg and drag dscoder onto the Applications folder shown beside it. Do this before the next step — the command below names that location.

  2. Clear the download flag

    If you open dscoder now, macOS refuses and says the app is damaged or cannot be opened. It is not damaged. When you downloaded it, macOS attached an invisible label to the file meaning "this came from the internet", and because nobody has signed the app, macOS will not offer you a way past that label — there is no Open anyway button to press. You take the label off yourself.

    Open Terminal (Applications → Utilities → Terminal), paste this one line, and press Return:

    xattr -d com.apple.quarantine /Applications/dscoder.app

    What that does: xattr is the built-in tool for the hidden labels macOS keeps alongside a file. -d means delete one, and com.apple.quarantine is the name of the "downloaded from the internet" label. The command removes that one label from that one app. It does not change anything inside dscoder, it does not touch any other app, and it does not alter any setting on your Mac.

    Terminal prints nothing if it worked. That is the normal answer.

  3. Open dscoder

    Open it from Applications the usual way. It starts the engine, puts an icon in the menu bar, and opens the window.

  4. Expect to repeat this for every update

    An unsigned app is not allowed to replace its own files on macOS, so dscoder cannot update itself here. When a new version is out the app tells you, and you come back to this page, download it, and do steps 1 and 2 again. There is no automatic update on macOS.

After it is installed

It opens on your own machine first

The engine listens on 127.0.0.1:8479 and on nothing else. You can use dscoder on that computer straight away, with no account and nothing paired.

Reaching it from elsewhere is a separate step

Sign in, press Add a machine, and paste the code it gives you into the app. The computer then dials out and answers at dscoder.cc.cd/<name>.

You will need a DeepSeek account

dscoder drives a chat.deepseek.com web session rather than a paid API, so there is no key to buy. Sign in once, in the window it opens for you. The token stays on your machine, encrypted to your Windows login.

Removing it

Windows: Settings → Apps, then uninstall dscoder. macOS: drag it from Applications to the Bin. Your run history and settings live in ~/.dscoder; delete that folder too if you want nothing left.

The installer is not signed. The updates are checked.

These two are worth keeping apart, because they are different promises. Nobody has signed the installer you are about to run, and your operating system says so.

Once dscoder is installed, every update it fetches is a different matter: each release is signed on the maker's own computer with a key that has never been uploaded to the server handing the files out, and the app checks that signature — and the hash of every single file — against a key built into itself before writing anything. There is no prompt and no override. Whoever controls the download server can serve you an old release or no release; they cannot put a new line of code on your computer.

Only the Windows build has ever been run by anybody. The macOS disk images and the Linux AppImage above are built by the same step, on the same commit, and they are published here -- but nobody has opened one. If you are the first, whatever happens is worth knowing, including that it worked.

A Linux AppImage is published above as well. Tray icons are the part most likely to differ: some desktops have no tray at all, and dscoder sits in one.

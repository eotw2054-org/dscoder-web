Your folder, your branch, your history

The file it changed is the file you will commit. Nothing is copied to a container or a sandbox in somebody's cloud, because there is nowhere else for the work to be.

The app sits in the tray. Close the window and this computer is still reachable; quit it and nothing is left running.

Nothing listens on your computer. It dials out and holds the line open, so a request from your phone travels back down the connection your computer made. There is no port to forward, no router to touch, and nothing on your machine for anyone to knock on.

It checks its work by looking

Most of the ways an agent can be wrong are invisible to it. So before it says a thing is done, it serves the page, screenshots it, and looks at the screenshot — real vision, not a description it wrote for itself.

what you pay

Nothing

No card, no trial, and no larger plan that this one is a sample of. You need an account only so that one address knows which computers are yours.

what it runs on

A chat session, not a paid API

dscoder drives a DeepSeek web session from your computer rather than billing an API key. Several accounts take turns, which is what keeps the rate limiter quiet.

The sign-in token stays on the machine, encrypted to your Windows login. It is never uploaded anywhere.

Download

One installer. Nothing else has to be on the machine — dscoder is plain Node with no packages and no database.

Windows

10 and 11, 64-bit · size

Not published yet

Windows will warn you the first time you run it. SmartScreen shows a blue box saying "Windows protected your PC", and the button you need is not on it yet: click More info first, then Run anyway. You see this once, on the installer.

It installs into your own user folder and never asks for an administrator. From then on the app keeps itself up to date.

macOS

macOS version and later · Apple silicon and Intel · size

Not published yet

macOS will not open it until you clear the download flag yourself. Double-clicking gives you a message saying the app cannot be opened, and there is no "open anyway" button to press. Three steps:

  1. Open the disk image and drag dscoder into your Applications folder.
  2. Open Terminal (Applications → Utilities) and paste this line, then press Return: 
    xattr -d com.apple.quarantine /Applications/dscoder.app
    That removes one label macOS attaches to anything downloaded from the internet — the label is the only reason it refused. The command changes nothing inside the app and nothing else on your Mac.
  3. Open dscoder the normal way.

dscoder is not code-signed, and will not be

There is no developer certificate behind these files, so Windows and macOS both treat dscoder as software from an unidentified developer. That is a fact about how it is distributed, not a sign that something is wrong with your download, and the steps above are how you get past it.

On macOS it has one further consequence, and it is worth knowing before you install rather than after: an unsigned app is not allowed to replace its own files, so every macOS update is a manual download. dscoder will tell you when a new version is out; you download it and repeat the three steps. On Windows the app updates itself.
